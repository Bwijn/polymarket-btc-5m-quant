# 策略评估统计指标

## 为什么需要这些工具

1908 年,William Gosset 在吉尼斯啤酒厂需要用少量样本判断大麦质量,不能每次浪费整批原料。他发明了 t-test 来回答一个问题:

**"我观察到的结果,是真实规律还是运气?"**

交易中是同一个问题:我找到了真正的 edge,还是只是运气好?

---

## 标准差 Standard Deviation (std)

**衡量什么**: 每笔交易结果的离散程度。

```
std = sqrt( mean( (每笔PnL - 平均PnL)² ) )
```

我们的 std ≈ $1.07,意思是大部分单笔 PnL 落在 [均值 - $1.07, 均值 + $1.07] 之间。

- std 高 → 结果噪声大 → 需要更多样本才能发现信号
- std 低 → 结果稳定 → 更少样本就能判断

**直觉**: 每次交易的输赢波动越大,越难判断是否有真正的 edge。

---

## t-statistic

**衡量什么**: 信号强度相对噪声的比值。

```
t = (平均每笔PnL / std) × √样本数
```

**为什么要乘 √n**: 中心极限定理 — 数据越多,均值估计越可靠。
均值的误差 = std / √n,n 越大误差越小,信号越可信。

```
n=4,  胜率75% → t ≈ 1.0  → 可能纯粹运气
n=400, 胜率75% → t ≈ 10.0 → 几乎可以确定是真实 edge
```

**参考标准**:
- `|t| < 1.5` → 淹没在噪声里,无法判断
- `|t| > 2.0` → 信号开始有意义
- `|t| > 3.0` → 强信号

---

## p-value

**衡量什么**: 假设真实 EV = 0,出现当前结果或更极端情况的概率。

```
p = P(看到这么极端的结果 | 真实EV = 0)
```

**行业标准门槛**: p < 0.05 = "统计显著"
含义:如果真实 EV = 0,这种结果只有 5% 的概率是运气导致的。

**关键**: p-value 只说"显不显著",不说方向。需要同时看均值的正负。

```
p < 0.05 且 mean > 0  →  显著正EV  →  继续跑
p < 0.05 且 mean < 0  →  显著负EV  →  考虑换策略
p > 0.05              →  无法判断  →  继续积累数据,不动
```

**p > 0.05 时不要行动。** 那是噪声。

---

## Rolling Window EV

**为什么需要**: 累计均值可能掩盖近期衰减。Edge 消失时,累计数字还是正的,但最近 100 笔已经亏钱了。

```python
rolling_mean = mean(pnls[-100:])
rolling_std  = stdev(pnls[-100:])
rolling_t    = (rolling_mean / rolling_std) * sqrt(100)
```

**策略决策规则**:

| Rolling EV | t值 | 行动 |
|---|---|---|
| > 0 | 任意 | 继续跑 |
| < 0 | t > -1.96 (p > 0.05) | 等待,积累数据 |
| < 0 | t < -1.96 (p < 0.05) | Edge 可能消失,调查 |
| < 0 | t < -2.58 (p < 0.01) | Edge 消失,换策略 |

## Python 实现

```python
import statistics, math

def ev_stats(pnls: list[float]) -> dict:
    n = len(pnls)
    if n < 2:
        return {}
    mean = sum(pnls) / n
    std = statistics.stdev(pnls)
    t = (mean / std) * math.sqrt(n)
    return {"n": n, "mean": mean, "std": std, "t": t, "ev_pct": mean * 100}
```
